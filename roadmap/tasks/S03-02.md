## Не входит

Нет скачивания случайного holiday API, выбора календаря по местоположению пользователя или изменения существующих delivery dates.

## Критерии приёмки

1. Пятница, выходной, праздничный день и последовательность исключений дают согласованную владельцем следующую дату.
2. Граница года не зависит от hardcoded 2026 list; неизвестный календарь следующего периода даёт blocker, а не ложную рабочую дату.
3. Cut-off проверен до/на/после границы в согласованной timezone, включая переход offset при необходимости.
4. Preview показывает источник calendar version и вычисленную дату; локальная timezone компьютера не меняет итог незаметно.
5. Clock/calendar переданы как тестируемые входы; generated injected function не зависит от потерянного outer helper.

## Test-first и команды

Ожидаемые значения берутся из решения владельца; сначала воспроизвести границу года и отсутствие calendar coverage без реальных delivery changes.

```sh
node --test test/unit/depot-calendar.test.mjs
```

Это целевая команда карточки: указанные product test files нужно создать при её выполнении. Их нет в исходном ZIP, и они не объявлены пройденными. Сначала подготовить harness по зависимостям. При изменении имени теста обновить карточку и evidence до заявления о GREEN.

После узкой проверки выполнить затронутые регрессии и обязательные lint/build проверки по [toolchain](../../docs/toolchain.md). Для injected code отдельно проверять serialization, для UI — реальный browser harness. Не выполнять real Gmail/Drive/depot/AI calls по одному разрешению редактировать код.

## Контракт данных и побочных эффектов

Это операционный календарь организации, не утверждение о правовых государственных выходных. Наличие даты в коде не подтверждает бизнес-допуск.

Новый SQL/серверный стек не вводится: сохраняются Chrome + существующий Node bot + Firestore. Изменения config/queue/storage требуют явной совместимости и recovery; не создавать несуществующий src/storage по старому шаблону. Правила безопасности: [security](../../docs/security-and-privacy.md), [контракты](../../docs/contracts.md).
