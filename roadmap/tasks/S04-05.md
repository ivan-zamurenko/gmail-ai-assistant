## Не входит

Нет сканирования рабочего аккаунта целиком, массового переноса, использования customer labels или автоматического production допуска.

## Критерии приёмки

1. Перед запуском записан разрешённый test account/folder scope без токенов и персональных данных; production папки исключены.
2. Реальный preview не создаёт папок и не меняет metadata; отсутствие эффектов подтверждено чтением до/после.
3. Один разрешённый apply создаёт ожидаемое имя/путь; повтор/reopen не создаёт дубликат.
4. Недостаточные permissions, отмена и хотя бы один управляемый failure имеют честные outcomes; небезопасный failure не провоцируется на чужих файлах.
5. Evidence раздельно описывает реальные вызовы, synthetic fault tests и непроверенные случаи; cleanup только созданных тестом объектов по разрешению.

## Test-first и команды

Manual integration: подготовить checklist до вызовов. Нет стенда — env_blocked; unit mock GREEN не заменяет roundtrip.

```sh
node tools/roadmap.mjs validate && node tools/check-docs.mjs
```

Команда уже существует в комплекте. Она проверяет документы/tooling, а не заменяет ручную или внешнюю проверку, описанную ниже.

После узкой проверки выполнить затронутые регрессии и обязательные lint/build проверки по [toolchain](../../docs/toolchain.md). Для injected code отдельно проверять serialization, для UI — реальный browser harness. Не выполнять real Gmail/Drive/depot/AI calls по одному разрешению редактировать код.

## Последовательность реализации

1. Подтвердить gates и получить synthetic fixtures в отдельной папке.
2. Выполнить утверждённый checklist preview/apply/repeat/failure.
3. Записать sanitized evidence и оставшиеся browser/provider gaps.

## Контракт данных и побочных эффектов

Разрешение ограничено конкретным тестовым scope. Credentials вводятся вне чата. OAuth token не включается в screenshot/log/evidence.

Новый SQL/серверный стек не вводится: сохраняются Chrome + существующий Node bot + Firestore. Изменения config/queue/storage требуют явной совместимости и recovery; не создавать несуществующий src/storage по старому шаблону. Правила безопасности: [security](../../docs/security-and-privacy.md), [контракты](../../docs/contracts.md).
