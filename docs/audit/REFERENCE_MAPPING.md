# Как адаптирован предоставленный эталон

> Історичний звіт комплекту, не поточна перевірка. Актуальний стан: [LOCAL_BASELINE](LOCAL_BASELINE.md).

## Принцип переноса

Перенесена **организация инженерной работы**, а не доменная модель другого приложения. Эталон содержит 134 задачи/18 стадий для нового веб-продукта; DPD — уже существующее расширение с иным стеком и рисками. Сохранение тех же чисел или выдумывание SQL-миграций ради внешнего сходства сделало бы комплект неточным.

Термины карточка, RED/GREEN, evidence, CURRENT, gate, один writer и read-only reviewer сохранены. Их значения адаптированы к Chrome, Drive, Gmail и depot. Для локальных инструментов выбран Node, уже используемый проектом; поэтому вместо `tools/roadmap.py` поставляется `tools/roadmap.mjs`. Это явное отличие, не скрытая зависимость от Python.

## Найденные внутренние расхождения эталона

Отдельные образцы отражают разные моменты разработки: `00_READ_FIRST.md` говорит, что все application tasks todo; отдельный README описывает уже выполненные S00-01…S00-07. Отдельный AGENTS уточняет работу в корне существующего репозитория, тогда как встроенная HTML-копия описывает изолированную новую папку.

В нашем комплекте эти состояния не смешаны. Состояние DPD взято из ZIP; все новые карточки модернизации имеют todo. Выполненный аудит отмечен отдельно как KIT-00, а не как завершение application tasks. HTML создаётся из текущих Markdown и state, чтобы уменьшить риск второй устаревшей копии.

## Что намеренно не переносится

Тарифы, Stripe, тренировки, медицинские/нагрузочные правила, Supabase, SQLAlchemy, FastAPI, базы данных и чужие Git URLs. Также не перенесены чужие model IDs, версии toolchain и параметры максимального reasoning без проверки их применимости.

Из образца взята дисциплина контекста: общие инструкции краткие, подробности открываются по задаче. Это не ограничение глубины документации: полный справочник остаётся в отдельных Markdown, а не дублируется в каждый agent prompt.
