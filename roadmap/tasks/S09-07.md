## Acceptance — критерии приёмки

1. При отсутствии key/drop/валидного Eircode базовая карточка формируется без Maps fetch и без выдуманного расстояния.
2. Network reject, timeout, non-2xx и invalid JSON/image не теряют status/history; выводится ограниченная диагностика optional map unavailable.
3. Расстояние обозначено как по прямой, не driving distance или proof of delivery; synthetic координаты проверяют единицы и граничные значения.
4. API key остаётся только в серверном request и не появляется в logs, Discord links, payload, filenames или exceptions; тест использует fake key marker.
5. Количество попыток и timeout bounded; cache/retention геоданных не вводятся без политики. Live Maps вызовы не делаются без G_DISCORD_ACCESS/G_PRIVACY и согласованного бюджета.
