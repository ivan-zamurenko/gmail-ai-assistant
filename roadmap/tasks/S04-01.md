## Не входит

Нет рекурсивного сканирования всего Drive по умолчанию, удаления файлов, скачивания приватного корпуса или расширения OAuth scopes.

## Критерии приёмки

1. Folder ID/поддерживаемый URL нормализуется до запроса; чужой URL, пустой ID и неожиданная query форма отклоняются.
2. Две и более страницы объединены без потери ID; повторяющийся nextPageToken/превышенный budget даёт явную ошибку, не цикл.
3. Trashed/non-image/unsupported items не скачиваются как изображения; правила выбора отражены в summary.
4. Один и тот же file ID на нескольких страницах обрабатывается однократно в рамках snapshot.
5. 403/404 выбранной папки и partial page failure не превращаются в пустой успешный scan.

## Test-first и команды

Fake Drive list возвращает несколько страниц, token loop и forbidden; assertions проверяют полный набор и максимальное число calls.

```sh
node --test test/unit/drive-list.test.mjs
```

Это целевая команда карточки: указанные product test files нужно создать при её выполнении. Их нет в исходном ZIP, и они не объявлены пройденными. Сначала подготовить harness по зависимостям. При изменении имени теста обновить карточку и evidence до заявления о GREEN.

После узкой проверки выполнить затронутые регрессии и обязательные lint/build проверки по [toolchain](../../docs/toolchain.md). Для injected code отдельно проверять serialization, для UI — реальный browser harness. Не выполнять real Gmail/Drive/depot/AI calls по одному разрешению редактировать код.

## Последовательность реализации

1. Сверить текущие list query и URL parsing.
2. Написать pagination/filter/failure fixtures.
3. Добавить bounded traversal и безопасный список кандидатов.

## Контракт данных и побочных эффектов

Read scope ограничен выбранной папкой и явно согласованной рекурсией. Наличие drive scope не разрешает перебор всего аккаунта.

Новый SQL/серверный стек не вводится: сохраняются Chrome + существующий Node bot + Firestore. Изменения config/queue/storage требуют явной совместимости и recovery; не создавать несуществующий src/storage по старому шаблону. Правила безопасности: [security](../../docs/security-and-privacy.md), [контракты](../../docs/contracts.md).
