## Acceptance — критерии приёмки

1. Чужой guild и depot actor без Administrator получают отказ до enqueueAndWait; для разрешённого actor одна команда создаёт не более одного вызова очереди.
2. todo проходит guild-check, но не требует depot Admin; userId берётся из interaction.user.id, а не из text/options.
3. При отсутствующем dry_run используется true; явне false є достатнім live-підтвердженням, без другого параметра. Проверка не рекламируется как привязка к preview — она реализуется S09-09.
4. Неизвестная command/subcommand, повреждённые options и неверный find number приводят к управляемому error, а не fallback в mutating handler; результат не содержит secret input.
5. Tests проверяют согласованность schema и handler, не запускают client.login/register. Неподключённые modes явно сообщают недоступность либо скрываются после reviewed schema update, без ложного успеха.
