Подготовлено 9 октября 2026 года. Репозиторные файлы настроены для DPD; их фактическая загрузка в твоём VS Code и доступность функций аккаунта ещё не проверены.

## 1. Что подключается

| Файл | Назначение |
|---|---|
| `.github/copilot-instructions.md` | Краткие постоянные правила проекта |
| `AGENTS.md` | Общий контракт разработки для совместимых агентов |
| `.github/instructions/*.instructions.md` | Дополнительные правила по затронутым путям |
| `.github/agents/dpd-review.agent.md` | Ограниченная роль reviewer |
| `docs/copilot/WORKFLOW_RU.md` | Полное руководство владельцу; не always-on контекст |
| `docs/copilot/settings.merge-example.json` | Необязательный пример настроек Local-режима |
| `.agents/skills/dpd-task-delivery/` | Workflow одной карточки, если выбранный инструмент обнаруживает skill |

Форматы instructions и правила обнаружения зависят от выбранного agent harness. Copilot и Local поддерживают проектные инструкции, но произвольное расширение с моделью не обязано их читать. Официальные источники: S-VSCODE-INSTRUCTIONS, S-GITHUB-INSTRUCTIONS в [SOURCES.md](docs/SOURCES.md).

## 2. Установка файлов

Открыть в VS Code **корень существующего `gmail-ai-assistant`**, а не родительскую папку с несколькими проектами. Перенести комплект по [INSTALL_RU.md](INSTALL_RU.md), сохраняя существующий Git и сравнивая одноимённые инструкции.

Убедиться, что имя файла точно `.github/copilot-instructions.md`, без `(1)`, `.txt` и лишнего уровня папки. `AGENTS.md` не вставлять целиком в Copilot-файл: в нём уже есть общий контракт. Большой справочник WORKFLOW не добавлять к каждому сообщению.

## 3. Проверить обнаружение

Выбрать Copilot/совместимый режим сессии. В поддерживаемом интерфейсе открыть `Chat: Open Customizations` → Instructions; проверить путь и отсутствие ошибок. Для диагностики можно использовать References ответа и customization diagnostics. Само утверждение модели «я прочитал AGENTS» не является независимой проверкой подключения. [S-VSCODE-INSTRUCTIONS; S-GITHUB-INSTRUCTIONS](docs/SOURCES.md)

Сначала отправить read-only запрос:

```text
Не меняй файлы и не запускай приложение.
Назови обнаруженные проектные инструкции, текущий task из CURRENT,
следующую карточку по node tools/roadmap.mjs next и команды проверок.
Отдельно укажи, чего ещё нет в исходном package.json и почему нельзя
проверять Drive Dry Run на рабочей папке.
```

Очікувана відповідь: чинний Chrome MV3/JS/esbuild і Discord-бот, поточна задача з CURRENT та next, наявний npm test і test/ suite, виправлений folder dry-run з регресіями. Если агент предлагает FastAPI/Stripe, новый проект или «готовый AI pipeline», остановить правки и исправить источник контекста.

## 4. Настройки JSON — только merge

[settings.merge-example.json](docs/copilot/settings.merge-example.json) включает поддержку project instructions/AGENTS в совместимом Local-режиме и исключает generated/private-noise каталоги из обычного поиска. Проверить наличие каждого параметра в установленной версии. Для другого harness его правила имеют приоритет; не считать Local-настройки универсальными.

Не заменять `.vscode/settings.json` целиком. В примере нет выбора модели, бюджета, auto-approve, отключения подтверждений и remote credentials. `search.exclude` не защищает secrets от прямого чтения инструментом.

## 5. Модель, контекст и роли

Не привязывать проект к чужому имени модели из эталона. Выбрать доступную модель под задачу и фиксировать результат: выполненные criteria, число неудачных циклов, замечания review и фактический расход, если интерфейс его показывает. Для прав доступа, неопределённого write и serialization нужен более тщательный разбор, но высокий reasoning сам по себе не создаёт правильный контракт.

Одна сессия — обычно одна карточка. В контекст дать AGENTS/CURRENT/карточку и релевантные модули. Не прикладывать весь архив, `.git`, `node_modules`, `dist` и реальные фотографии.

Reviewer role находится в `.github/agents/`. Указанные tool groups `read`/`search` нужно проверить в выбранном harness. Отключить edit/terminal/write tools в интерфейсе, если требуется фактическое ограничение. Markdown-роль не является самостоятельным sandbox. [S-VSCODE-AGENTS](docs/SOURCES.md)

## 6. Первая рабочая карточка

После read-only проверки использовать [AGENT_START_RU.md](AGENT_START_RU.md). Выполнить S00-01, а не сразу всю стадию. Принятие инструкции не разрешает live Drive/depot, auto-send или передачу данных AI.

После завершения должны существовать фактические CURRENT/state/evidence, reviewed diff и честный commit/push status. Локальные команды документации не подтверждают, что Chrome-расширение протестировано.

## 7. Чего этот комплект не делает

Не устанавливает Copilot, не авторизует GitHub, не меняет подписку/квоту, не выбирает модель и не гарантирует экономию. Не применяет Codex TOML и не включает внешний доступ. Проверка файлов выполнена отдельно от проверки твоего редактора.

Полный рабочий процесс: [WORKFLOW_RU.md](docs/copilot/WORKFLOW_RU.md). Отдельная настройка Codex: [CODEX_SETUP_RU.md](CODEX_SETUP_RU.md).
