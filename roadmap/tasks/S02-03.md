## Не входит

Нет массовой миграции всего Drive, придуманной timezone, новой организации папок без решения или скрытого overwrite.

## Критерии приёмки

1. Источник filing date явно выбран владельцем: metadata, дата сканирования или иной подтверждённый источник; код не выбирает его молча.
2. Timestamp около границы суток проверен с согласованной timezone; truncation первых 10 символов не подменяет согласованную дату.
3. Unknown, known, parcel suffix и collision suffix строятся одинаково при повторном запуске на одинаковом snapshot.
4. Невалидная дата/расширение и отсутствие metadata возвращают явную причину, а не сегодняшнюю дату без обозначения fallback.
5. Существующее имя с непроверенным номером не считается доказательством known; политика переименования/оставления отражена в preview.

## Test-first и команды

Сначала согласованные boundary examples владельца записываются как fixtures; RED по дате или stale known фиксируется относительно этих примеров, не чужого календаря.

```sh
node --test test/unit/label-names.test.mjs
```

Это целевая команда карточки: указанные product test files нужно создать при её выполнении. Их нет в исходном ZIP, и они не объявлены пройденными. Сначала подготовить harness по зависимостям. При изменении имени теста обновить карточку и evidence до заявления о GREEN.

После узкой проверки выполнить затронутые регрессии и обязательные lint/build проверки по [toolchain](../../docs/toolchain.md). Для injected code отдельно проверять serialization, для UI — реальный browser harness. Не выполнять real Gmail/Drive/depot/AI calls по одному разрешению редактировать код.

## Контракт данных и побочных эффектов

Naming policy version и источник даты входят в plan. Изменение будущего правила не переписывает историю файлов автоматически. Original filename может быть чувствительным и не переносится в открытые logs.

Новый SQL/серверный стек не вводится: сохраняются Chrome + существующий Node bot + Firestore. Изменения config/queue/storage требуют явной совместимости и recovery; не создавать несуществующий src/storage по старому шаблону. Правила безопасности: [security](../../docs/security-and-privacy.md), [контракты](../../docs/contracts.md).
