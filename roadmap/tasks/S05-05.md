## Не входит

Нет live создания drafts, send, mark-as-read/archive без политики или утверждения что mock доказал OAuth scopes.

## Критерии приёмки

1. Draft payload использует подтверждённый recipient/thread/reply headers; изменение этих полей пользователем повторно проверяется.
2. Два нажатия create для одного подтверждённого proposal не отправляют параллельные create requests.
3. Timeout после принятого create сохраняет uncertain и запускает разрешённую сверку; blind повтор не создаёт duplicate draft.
4. Source label изменяется только на согласованном шаге и после подтверждённого эффекта; failure label update не стирает факт созданного draft.
5. Ни один путь не вызывает messages.send/drafts.send. Fixture test перечисляет все endpoints и запрещает send.

## Test-first и команды

Начать с tests exact MIME/thread headers, duplicate click и lost create response; fake transport проверяет отсутствие send при любом outcome.

```sh
node --test test/unit/gmail-drafts.test.mjs
```

Это целевая команда карточки: указанные product test files нужно создать при её выполнении. Их нет в исходном ZIP, и они не объявлены пройденными. Сначала подготовить harness по зависимостям. При изменении имени теста обновить карточку и evidence до заявления о GREEN.

После узкой проверки выполнить затронутые регрессии и обязательные lint/build проверки по [toolchain](../../docs/toolchain.md). Для injected code отдельно проверять serialization, для UI — реальный browser harness. Не выполнять real Gmail/Drive/depot/AI calls по одному разрешению редактировать код.

## Контракт данных и побочных эффектов

Локальный operation ID не является серверной idempotency guarantee Gmail. Draft lifecycle и label update — отдельные effects с partial/uncertain outcomes. Реальный roundtrip только S08-03 после gates.

Новый SQL/серверный стек не вводится: сохраняются Chrome + существующий Node bot + Firestore. Изменения config/queue/storage требуют явной совместимости и recovery; не создавать несуществующий src/storage по старому шаблону. Правила безопасности: [security](../../docs/security-and-privacy.md), [контракты](../../docs/contracts.md).
