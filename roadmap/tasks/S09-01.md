## Acceptance — критерии приёмки

1. Тест сравнивает значения COMMANDS, RESCHEDULE_MODE, STATUS, TASK_SCHEMA_VERSION и TASKS_COLLECTION обоих runtime; намеренное изменение одного зеркала вызывает конкретный FAIL.
2. Фикстуры version 0/unknown command/bad conId/nonboolean dryRun отвергаются до Chrome API и до любого depot effect; не подменять executeTask общей заглушкой.
3. Схема pending task отдельно описывает requestedBy и executorUid; одно поле не подменяет другое и пользовательский args не может незаметно переопределить верхнеуровневую identity.
4. Зберегти реалізовані all/parcel/barcodes/retry; перевірити узгодженість modes між runtime та відхилення невідомого mode/некоректних args до depot effect. Не вимагати відмову для вже підтримуваних режимів; використати чинні executor regressions без дублювання.
5. Четыре старых security cases сохранены; contract test не импортирует bot index/firebase startup и не требует real local.js/service account.
