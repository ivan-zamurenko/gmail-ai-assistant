## Не входит

Нет массового переименования старого Drive, automatic overwrite, удаления duplicates или фиктивной верификации по filename.

## Критерии приёмки

1. План фиксирует file ID, исходные name/parents/version metadata, candidate result, целевой путь и naming policy version.
2. Изменение remote metadata после preview вызывает stale outcome до PATCH; решение не опирается только на имя.
3. Коллизия target filename разрешается согласованным deterministic suffix или ручным отказом; существующий чужой файл не заменяется.
4. ALREADY_NAMED с неуспешной проверкой номера не маскирует unknown/ambiguous результат и не получает статус verified по одному имени.
5. Apply повторно проверяет folder/file scope и ambiguity; dryRun остаётся с нулём mutations после рефакторинга.

## Test-first и команды

Сначала fixtures stale metadata, duplicate name и already-named unknown; отдельный regression запускает S01-01 probe.

```sh
node --test test/unit/drive-plan-apply.test.mjs
```

Это целевая команда карточки: указанные product test files нужно создать при её выполнении. Их нет в исходном ZIP, и они не объявлены пройденными. Сначала подготовить harness по зависимостям. При изменении имени теста обновить карточку и evidence до заявления о GREEN.

После узкой проверки выполнить затронутые регрессии и обязательные lint/build проверки по [toolchain](../../docs/toolchain.md). Для injected code отдельно проверять serialization, для UI — реальный browser harness. Не выполнять real Gmail/Drive/depot/AI calls по одному разрешению редактировать код.

## Контракт данных и побочных эффектов

Remote metadata snapshot — условие актуальности, не вечная блокировка. Drive update не обещает атомарность всего пакета; каждый item имеет собственный outcome.

Новый SQL/серверный стек не вводится: сохраняются Chrome + существующий Node bot + Firestore. Изменения config/queue/storage требуют явной совместимости и recovery; не создавать несуществующий src/storage по старому шаблону. Правила безопасности: [security](../../docs/security-and-privacy.md), [контракты](../../docs/contracts.md).
