## Не входит

Нет микросервисов, платной очереди, server migration без решения, keepalive workaround как гарантии или массового запуска реальных jobs.

## Критерии приёмки

1. ADR явно выбирает execution context с учётом DOM/canvas; decoder не переносится в service worker как будто там есть document.
2. Закрытие popup не стирает committed job state; повторное открытие показывает job ID и фактическое состояние.
3. Остановка и повторный запуск worker/runner обнаруживает незавершённый item и не выполняет mutation вслепую второй раз.
4. Message DTO валидируется; страница depot не может выдавать произвольные команды runner или получать Google token.
5. Новые manifest permissions/context нужны конкретной реализации и отдельно объяснены; старые extension identity fields сохранены.

## Test-first и команды

Создать lifecycle test закрытия popup/пересоздания execution context до реализации; обычный долгий promise в popup не удовлетворяет критерию.

```sh
node --test test/integration/drive-runner.test.mjs
```

Это целевая команда карточки: указанные product test files нужно создать при её выполнении. Их нет в исходном ZIP, и они не объявлены пройденными. Сначала подготовить harness по зависимостям. При изменении имени теста обновить карточку и evidence до заявления о GREEN.

После узкой проверки выполнить затронутые регрессии и обязательные lint/build проверки по [toolchain](../../docs/toolchain.md). Для injected code отдельно проверять serialization, для UI — реальный browser harness. Не выполнять real Gmail/Drive/depot/AI calls по одному разрешению редактировать код.

## Контракт данных и побочных эффектов

Storage journal обеспечивает recoverability, не бесконечную жизнь service worker. Chrome-specific подтверждение проводится browser test, не заменяется Node mock.

Новый SQL/серверный стек не вводится: сохраняются Chrome + существующий Node bot + Firestore. Изменения config/queue/storage требуют явной совместимости и recovery; не создавать несуществующий src/storage по старому шаблону. Правила безопасности: [security](../../docs/security-and-privacy.md), [контракты](../../docs/contracts.md).
