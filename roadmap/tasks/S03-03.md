## Не входит

Нет изменения даты ради проверки, продления прав оператора или интерпретации неизвестных статусов через AI.

## Критерии приёмки

1. PENDING, DELIVERED, OFD и GOODS HELD имеют отдельные подтверждённые решения, а не одно скопированное CHANGE_DATE правило.
2. Неизвестный статус, отсутствующие обязательные данные и неподдерживаемая note classification запрещают изменение с явной причиной.
3. Регистр/пробелы допустимо нормализованы; отрицание в note не превращается в позитивный match из-за одной подстроки.
4. Ручное разрешение одного случая не расширяет policy на все отправки и не сохраняется как глобальный bypass.
5. Каждый разрешённый и запрещённый переход покрыт тестом; оригинальное спорное поведение задокументировано как baseline, не требование.

## Test-first и команды

Сначала превратить подтверждённую владельцем таблицу в независимые test cases. До ответа не угадывать допустимость DELIVERED/OFD.

```sh
node --test test/unit/depot-policy.test.mjs
```

Это целевая команда карточки: указанные product test files нужно создать при её выполнении. Их нет в исходном ZIP, и они не объявлены пройденными. Сначала подготовить harness по зависимостям. При изменении имени теста обновить карточку и evidence до заявления о GREEN.

После узкой проверки выполнить затронутые регрессии и обязательные lint/build проверки по [toolchain](../../docs/toolchain.md). Для injected code отдельно проверять serialization, для UI — реальный browser harness. Не выполнять real Gmail/Drive/depot/AI calls по одному разрешению редактировать код.

## Последовательность реализации

## Контракт данных и побочных эффектов

Policy возвращает allowed/denied/needs-review и reason; сам policy calculator не отправляет форму. Data freshness проверяется повторно перед apply.

Новый SQL/серверный стек не вводится: сохраняются Chrome + существующий Node bot + Firestore. Изменения config/queue/storage требуют явной совместимости и recovery; не создавать несуществующий src/storage по старому шаблону. Правила безопасности: [security](../../docs/security-and-privacy.md), [контракты](../../docs/contracts.md).

## Критерий завершения
