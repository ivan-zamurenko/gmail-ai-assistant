# Project skill: минимум, который нужен

> **Адаптація до робочого проєкту, 2026-10-23.** Поточний стан і пріоритет рішень: [LOCAL_BASELINE](audit/LOCAL_BASELINE.md). Нижче збережено план комплекту v1.2; його вихідний ZIP і старі перевірки не є поточним checkout. Майбутні задачі не запускаються автоматично. Спілкування з власником — українською.


В комплекте один узкий instruction-only skill — `dpd-task-delivery`. Его задача: провести агента через одну карточку существующего DPD Assistance и корректно сохранить evidence/checkpoint. Он не настраивает GitHub, Google OAuth, Chrome и paid model access.

## Когда использовать

При прямом поручении реализовать/продолжить определённую DPD-карточку в репозитории с AGENTS/CURRENT/roadmap. Не использовать его, чтобы автоматически начать правки по запросу «объясни функцию» или «проверь diff». Для review существует отдельное read-only поручение.

## Ограничения

Нет установочных hooks, скрытых subagents, сетевых scripts и live API tools. Skill указывает на файлы рабочего репозитория и потому не является самостоятельным runtime. Если этих файлов нет, сообщить об отсутствии контекста, не реконструировать весь проект из памяти.

Discovery проверяется в используемом агенте. Если он не поддерживает `.agents/skills`, следовать AGENTS/карточке без фиктивного заявления о skill invocation. Не добавлять чужие скачанные skills ради количества; сначала проверить происхождение, инструкции и scopes.

Формат и расположение Codex skills: S-CODEX-SKILLS в [SOURCES.md](SOURCES.md). Инструкция создана и проверяется отдельно от фактического запуска в пользовательском IDE.
